# Устаревшие bat-файлы

Раньше было 5–6 `.bat` в корне — теперь **один вход**: `start_viu.bat`.

| Старый файл | Замена в окне Вью |
|-------------|-------------------|
| `check_unity.bat` | Кнопка **Отчёт Unity** |
| `setup_shanya.bat` | **Init проект** + **Deploy скрипты** |
| `check_blender.bat` | **Blender: сцена** / **rig** |
| `console.bat` | Чат справа или `python -m viu tool …` |

Старые bat только открывают GUI (для ярлыков на рабочем столе).
