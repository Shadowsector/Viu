# Скрипты Viu

В корне остался **один файл запуска** — `Viu.cmd`. Всё остальное убрано.

| Что | Файл | Назначение |
|-----|------|------------|
| корень | `Viu.cmd` | запуск Вью (двойной клик) |
| корень | `run_gui.pyw` | внутренний запуск окна без консоли |
| корень | `bootstrap_update.py` | самообновление (первая установка) |

Всё остальное — обновление, сбор логов, диагностика, ярлык на рабочий стол —
делается кнопками и меню внутри окна Вью. Старые `*.bat` Вью удаляет сама
при первом запуске новой версии.
