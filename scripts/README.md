# Скрипты Viu

В корне остался **один файл запуска** — `Viu.cmd`. Всё остальное убрано, чтобы
не путаться.

| Где | Файл | Назначение |
|-----|------|------------|
| корень | `Viu.cmd` | запуск Вью (двойной клик) |
| корень | `diagnose.bat` | диагностика, окно не закрывается |
| `setup/` | `make_shortcut.bat` | ярлык «Вью» на рабочий стол |
| `legacy_scripts/` | старые `.bat`/`.vbs` | не нужны, оставлены на всякий случай |

Обновление и сбор логов теперь делаются кнопками внутри окна Вью (группа «Вью»),
а не отдельными bat-файлами.
