# Asset-пайплайн: домик / сарай → Unity

Один сценарий, одна кнопка. Всё остальное — «Ещё» для ручного доступа.

## Четыре шага (только «▶ Следующий шаг»)

| # | Что делает Вью | Что делает Ден |
|---|----------------|----------------|
| **1. Inbox** | Prepare: текстуры, pack, свет, `*_prepared.blend` | Глянуть Blender (стены, мусор). Ctrl+S если правил. |
| **2. Разметка** | Окно «Очередь разметки» — только **Props** | Вес + галочки. Building/Landscape уже shell. |
| **2b. Стена** *(если notes.txt `open_wall=front`)* | Подсказка bisect | Отделить `Wall_front` в Blender, Ctrl+S |
| **3. Экспорт** | FBX → Library + Unity `Assets/Environment/` | Проверить папку в Unity |
| **4. Готово** | — | Новый asset → Inbox |

Подпись текущего шага — под заголовком «Действия» в боковой панели.

## Inbox — единственный вход

```
U:\Viu\Inbox\
  Old Stables\          ← папка-пак
    Old Stables.blend
    textures\
    notes.txt           ← опционально для сарая
```

После шага 1 Inbox **очищается**, исходник уходит в `Library\Blender\`.

**Не клади** второй домик в Inbox, пока не закончил разметку первого — иначе путаница с `Old Stables_2`.

## Что убрали / спрятали

- **«Принять asset»** больше **не лезет в Library**, если Inbox пуст — именно это открывало старый `Old Stables_2` без стены.
- **Оверлей / в глубину / на экран** — только на этапе playtest, после сборки exe. Не имеют отношения к импорту домика.
- **Разметить / Экспорт FBX** в «Ещё» — дубли «Следующего шага», показываются только когда уместны.

## Dollhouse (Wall_front)

1. `notes.txt` с `open_wall=front` рядом с blend **до** prepare.
2. После prepare — bisect в Blender, объект **`Wall_front`** (имя важно для экспорта).
3. Экспорт кладёт `dollhouse_wall` в `<slug>.viu.json`.

Если экспорт пишет «Wall_front не найден» — prepared-файл без стены (старая версия или не сохранил Blender).

## Когда что в «Ещё»

| Кнопка | Когда нужна |
|--------|-------------|
| Принять из Inbox (повтор) | Inbox не пуст, хочешь переprepare |
| Разметить предметы | Пропустил окно разметки |
| Экспорт FBX | Пропустил экспорт |
| Оверлей | Playtest Шани у панели — **не** часть импорта |

## Агент / чат

Переprepare из Library: `prepare_unity_asset` с `blend_file=...` или `allow_library_fallback=1`.
