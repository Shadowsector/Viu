# Сейчас делаем вот это (просто)

Вью умеет многое. **Сейчас** нам нужно только одно:  
собрать **тело Шани** и поставить его в игру.

Остальное (видео из Comfy, Cascadeur, съёмка анимаций) — **на паузе**.  
Кнопки спрятаны, код не удалён. Вернуть кнопки: `VIU_SHOW_PAUSED_UI=1`.

## Два тела — это важно

«Своё тело» — **не** твоя фотография и **не** «достать из D:\\HS2».

| Роль | Что это | Откуда |
|------|---------|--------|
| **Образец** | Erisa — только пропорции (образец формы) | `U:\Desktop Mascot\Women\…` (Smutbase) → Inbox |
| **Рабочее** | Тело, которое реально пойдёт в игру | Тоже из `Desktop Mascot\Women` (часто другой пак Smutbase / DAZ-база с CC0 или CC-BY) |

В Blender:

1. Открываешь Erisa.  
2. **Append** или **Import** рабочего тела из второго файла.  
3. Shrinkwrap: модификатор на **рабочем**, Target = Erisa.  
4. В игру уезжает **рабочее** (с Rigify), не образец.

Если рабочего тела ещё нет в хламнике — сначала скачай с Smutbase пак с подходящей лицензией (лучше CC0 / CC-BY, не ND) в `Women`, потом в Inbox.
