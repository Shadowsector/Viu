# Сейчас делаем вот это (просто)

Собрать **тело Шани** в игру. Comfy/Cascadeur — на паузе.

## Как правильно с телами (и с «авторскими чувствами»)

| | Что | Куда |
|---|-----|------|
| **Образец** | Твоя карта из **HS2 Studio** (пропорции) | Только Blender как лекало. **Не** в Unity. |
| **Рабочее** | Тело со **Smutbase** (лучше CC0 / CC-BY) | Shrinkwrap/правка → Rigify → **в игру** |

Идея: обтянуть **Smutbase** по форме **твоей HS2-карты**.  
Не «одно Smutbase вокруг другого Smutbase».  
Erisa не обязательна, если пропорции уже заданы твоей картой.

### Почему не «просто взять тело из HS2 и править»

Карту в Studio ты крутил сам, но **меш/текстуры базы — от Illusion**.  
Положить их в Анабарру = тащить чужой базовый ассет. Для личной машины риск ниже,  
но чистый путь — в билде только Smutbase (открытая лицензия), HS2 лишь лекало.

### Короткий рецепт

1. Экспорт своей HS2-карты → Inbox (образец).  
2. Пак Smutbase из `Desktop Mascot\Women` → Inbox (рабочее).  
3. Blender: оба в сцене → по желанию Shrinkwrap (рабочее → Target=образец) → убрать образец.  
4. Rigify на рабочем → FBX → Humanoid.
