# Heartbeat и vision.md

## vision.md

Файл: **`U:\Viu\.viu\vision.md`**

Общее направление игры — не только сухой roadmap. Вью читает и дополняет:
- фокус (сарай, оверлей, сюжет);
- идеи анимаций, сцен, механик;
- решения Дена из чата.

Инструменты агента: `vision_read`, `vision_append`.

## Heartbeat (таймер)

По умолчанию **раз в 20 минут** (`VIU_HEARTBEAT_MIN=20`) — только когда Ден **дома**.
Выключить: `0`. Вью предлагает следующую дыру графа и спрашивает Дена.

```env
VIU_HEARTBEAT_MIN=20
```

## Away-пинг (меня нет)

Когда статус **«Меня нет — работай сама»**, Вью пишет в Telegram **сама** — без вопросов, 2–3 раза в сутки (по умолчанию **3**).

```env
VIU_AWAY_PING_PER_DAY=3
```

`0` = выкл. Максимум 6. Интервал ≈ `24ч / N` с небольшим разбросом. Тихие часы (`VIU_QUIET_HOURS`) соблюдаются.

Инструмент агента: `presence_set away` / кнопка в GUI.

## Away + Comfy

По умолчанию в режиме «нет дома» **Comfy сама не поднимается** (`VIU_AWAY_AUTO_COMFY=0`).
Включить авто-съёмку снова: `VIU_AWAY_AUTO_COMFY=1` или `away_auto_comfy` в runtime.

## Тихие часы

С **00:00 до 07:00** (локальное время ПК) Viu **не** шлёт:
- heartbeat в Telegram;
- проактивные «✅ Готово» после задач.

**На твои сообщения** в Telegram она отвечает и ночью — тихие часы не глушат диалог.

Настройка в `Viu.cmd` или `.env`:

```env
VIU_QUIET_HOURS=0-7
```

`0-0` = выкл.

## Reflect vs work

| Сообщение | Режим |
|-----------|--------|
| «привет», «мы дом размечали» | **reflect** — думает, отвечает |
| «следующий шаг», кнопка ▶ | **work** — делает |

Reflect может вызвать `unity_close`, если Unity висит, а Play нажать некому.
