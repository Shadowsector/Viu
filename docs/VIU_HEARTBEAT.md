# Heartbeat и vision.md

## vision.md

Файл: **`U:\Viu\.viu\vision.md`**

Общее направление игры — не только сухой roadmap. Вью читает и дополняет:
- фокус (сарай, оверлей, сюжет);
- идеи анимаций, сцен, механик;
- решения Дена из чата.

Инструменты агента: `vision_read`, `vision_append`.

## Heartbeat (таймер)

По умолчанию **раз в 20 минут** (`VIU_HEARTBEAT_MIN=20`). Выключить: `0`.
Вью предлагает следующую дыру графа и спрашивает Дена.

```env
VIU_HEARTBEAT_MIN=20
```

## Тихие часы

С **00:00 до 07:00** (локальное время ПК) Viu **не** шлёт:
- heartbeat в Telegram;
- проактивные «✅ Готово» после задач.

**На твои сообщения** в Telegram она отвечает и ночью — тихие часы не глушат диалог.

Настройка в `Viu.cmd` или `.env`:

```env
VIU_QUIET_HOURS=0-7
```

`0-0` = выкл.

## Reflect vs work

| Сообщение | Режим |
|-----------|--------|
| «привет», «мы дом размечали» | **reflect** — думает, отвечает |
| «следующий шаг», кнопка ▶ | **work** — делает |

Reflect может вызвать `unity_close`, если Unity висит, а Play нажать некому.
