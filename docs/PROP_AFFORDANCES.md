# Разметка предметов — логика взаимодействий

Краткая шпаргалка для Дена и для Unity.

## Две шкалы

| Роль | Примеры | Что размечаем |
|------|---------|---------------|
| **shell** | стены, крыша, сосна за сараем | climb, встать, сидеть, спать — **без веса** |
| **interactive** (Props) | стул, бочка, топор, дверь | вес, grab, открыть, кинуть, в карман |
| **atmosphere** | Fog, Dust | ничего — остаётся в сцене для красоты |
| **undefined** | Plane.002, Cube… | авто-пропуск — служебный меш |

«Сидеть задом» убрали из разметки — это выбор анимации у персонажа, не свойство стула.

## Средневековый сарай — типичные Props

| Предмет | Действия |
|---------|----------|
| Стул / лавка | sit, lean |
| Кровать / солома | sleep, sit |
| Стол | lean |
| Дверь / ворота | open, move |
| Сундук | open |
| Бочка | move; sit — если хочешь комедию |
| Топор, подкова | grab, throw, pocket |
| Монеты | grab, pocket, **stackable** |
| Тарелка, кувшин, чаша | **tableware** — взять (grab), **не** eat |
| Яблоко, хлеб | **food** — eat |
| Свеча | decor; grab — если «снять со стола» |
| Plane.002, Cube… | **undefined** — служебный меш Blender, авто-пропуск |

## Shell / деревья

- **Сосна, Great Brome** — shell, climb, stand_on (Шаня залезет; алхимичка — только если у персонажа `can_climb`).
- **Стены, балки** — shell, обычно без галочек; крыша — stand_on + climb.
