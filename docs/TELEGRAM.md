# Telegram-бот Вью

Вью может писать тебе в Telegram, когда нужен ответ или случилась ошибка. Ты отвечаешь с телефона — ответ попадает в чат Вью на ПК, агент продолжает работу.

## 1. BotFather (5 минут)

1. Открой Telegram, найди **@BotFather**.
2. Отправь `/newbot`.
3. Имя бота (любое): например `Viu Anabarra`.
4. Username (уникальный, на `bot`): например `viu_anabarra_bot`.
5. BotFather пришлёт **токен** вида `7123456789:AAH...` — **никому не показывай**, это пароль бота.

## 2. Настройка на ПК (U:\Viu)

Создай или дополни файл **`U:\Viu\.env`** (или переменные в `Viu.cmd`):

```env
VIU_TELEGRAM_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
VIU_TELEGRAM_ENABLED=1
```

Владелец по умолчанию уже зашит: **Telegram ID `103833998` (Ден)**. Чужие аккаунты бот молча игнорирует — даже `/start`.

Опционально:

```env
# Явно (и так дефолт):
VIU_TELEGRAM_OWNER_IDS=103833998
# Исходящий чат (обычно совпадает с owner в личке):
VIU_TELEGRAM_CHAT_ID=103833998
```

Перезапусти Вью.

## 3. Привязка чата

1. В Telegram найди своего бота по username.
2. Нажми **Start** или напиши `/start` **со своего** аккаунта.
3. Бот ответит приветствием.
4. В окне Вью: **«Telegram: тест связи»** — должно прийти «Тест от Вью ✓».

## 4. Как это работает

| Событие | Telegram |
|---------|----------|
| Вью спросила через `ask_user` | ❓ Вопрос + «ответь сюда» |
| Ошибка инструмента | ⚠️ текст ошибки |
| Задача агента завершена | ✅ краткий итог |
| Ты пишешь боту | см. ниже |

**Болтовня** («привет», «ты супер») — Вью **думает**, потом **одним** сообщением отвечает. Размышления видны в окне Viu на ПК («размышляет»), в Telegram **не** шлётся отдельным текстом.

**Команда** («следующий шаг», «собери оверлей») — полный агент, делает сама.

Вью говорит о себе в **женском роде** (рада, готова — не «рад»).

**Важно:** держи **одну** копию Viu на ПК. Две запущенные — два ответа на одно сообщение.

**Тихие часы:** с 00:00 до 07:00 Viu не шлёт heartbeat и «✅ Готово» — но отвечает, если ты сам написал.
Настройка: `VIU_QUIET_HOURS=0-7` в `Viu.cmd`.

Команды бота:

- `/start` — привязать чат (только owner)
- `/status` — версия Вью, Unity, занята ли

## 5. Отключить уведомления

```env
VIU_TELEGRAM_NOTIFY_ERRORS=0
VIU_TELEGRAM_NOTIFY_DONE=0
```

Вопросы (`ask_user`) всё равно приходят.

## Безопасность

- Токен только в `.env` на твоём ПК, **не в git**.
- Бот принимает сообщения **только** от `VIU_TELEGRAM_OWNER_IDS` (дефолт `103833998`).
- Чужой `/start` не привязывает чат и не получает ответ.
- Если токен утёк — в BotFather: `/revoke` и новый токен.
