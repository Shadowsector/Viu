## Проблемы «неживой» картинки (типичные)

1. **Камера Instance** слишком общая — внутри сарая не чувствуется «комната».
2. **Пустой интерьер** — нет точек сидеть/спать/есть (props + анимации).
3. **Освещение** — один плоский свет, нет свечи/окна.
4. **Фасад** — сарай как плоская стенка коридора без деталей на переднем плане.
5. **Анимации дома** — нет sit/sleep/look_around → Шаня только ходит.

## Чеклист Дена (Unity Scene)

### Камера

1. Play → **W** до двери → вход в Instance.
2. Если кадр «не про сарай»:
   - `OverlayCameraPresets.instance.orthographicSize` ≈ **2.0–2.6** (крупнее = уютнее).
   - `feetScreenFraction` оставить ~0.07–0.10 внутри дома.
3. Проверь якорь `Anchor_HomeRoot` — pivot дома в центре кадра Instance.
4. F5 / `overlay_tune.json` — `orthoHalfHeight`, `characterDepthZ` (не ломать Facade).

### Геометрия сарая

1. Dollhouse: передняя стенка **скрывается** при `atHome` (см. `BUILDING_WALL_CUT.md`).
2. Внутри должны быть видны: пол, задняя стена, хотя бы один prop (стул / солома / стол).
3. Сосна/кусты — **shell** сзади, не загораживают дверь.

### Props (жизнь)

Минимум для «живого» сарая (разметка → `PROP_AFFORDANCES.md`):

| Prop | Affordance | Зачем |
|------|------------|--------|
| Стул / лавка | sit | sit_down → sit_idle |
| Солома / коврик | sleep | lie_down → sleep_idle |
| Стол + чаша | lean / tableware | look_around, take |
| Свеча | decor (+точечный свет позже) | атмосфера |
| Дверь | open | переход facade↔instance |

После разметки: новые клипы Wave 1–2 из каталога (sit, sleep, yawn…).

### Свет (простой шаг)

1. Point Light у свечи / окна (тёплый, низкая intensity).
2. Не трогать ULW chroma / HDR на overlay-камере (`OVERLAY_BASELINE.md`).

## Критерий «сарай ок»

1. Снаружи: фасад читается, Шаня у таскбара.
2. W → к сараю, масштаб уменьшается; у двери — вход.
3. Внутри: виден интерьер (не чёрная дыра), можно подойти к стулу.
4. S → выход на фасад без сломанной камеры.
5. Глазами Дена: «хочется посидеть», не «серый ящик».
