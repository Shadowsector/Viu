# Монстры: что делать по шагам

Обновление Вью тянет ветку **`cursor/viu-agent-core-65c2`**.  
После «Обновить Вью» перезапусти окно.

---

## Главное (без консольных команд)

1. Положи модели в `U:\Anabarra\Library\Lab\Creatures\Inbox\`
2. **«Разметить существ»** — скан + авто по именам + кнопки размеров.
3. **«Линейка существ»** — Вью **сама** находит Blender, гоняет скрипт, пишет `.blend`, открывает результат.  
   Ничего копировать в консоль не нужно.
4. Смотришь рост рядом с Шаней. Кто выбивается — снова разметка.

В чат: `разметить существ` / `линейка существ`.

---

## Что делает линейка технически

- Дедуп: `Goblin.fbx` + `Goblin.blend` → один (предпочитает `.blend`).
- Если моделей много — **отдельный .blend на класс** + `creature_lineup_overview.blend` (по одному представителю класса).
- Пишет измеренный рост обратно в каталог.
- Morphs (уши/хвосты/гениталии) **не трогает** — только scale корня.

Папка: `U:\Anabarra\Library\Lab\Creatures\Lineup\`

Если Blender не находится — в `Viu.cmd` строка `VIU_BLENDER_EXE=...` (см. docs/ANABARRA_FOLDERS.md).

---

## Почему «в папке 66», а скан говорит 103

Считается **каждый файл**, рекурсивно, плюс `Lab/Models/Inbox`.  
В линейке дубли имён схлопываются.

## Редкие флаги (чат)

| | |
|--|--|
| `creature_lineup size=small` | только один класс |
| `creature_lineup split=0` | одна общая сцена |
| `creature_lineup open=0` | не открывать файл |
| `creature_lineup prepare_only=1` | только JSON, без Blender |
