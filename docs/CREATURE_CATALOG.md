# Монстры: что делать по шагам

Обновление Вью тянет ветку **`cursor/viu-agent-core-65c2`**.  
После «Обновить Вью» перезапусти окно.

---

## Главное (без консольных команд)

1. Положи модели в `U:\Anabarra\Library\Lab\Creatures\Inbox\`
2. В окне Вью слева нажми **«Разметить существ»** (группа «Главное»).
3. Вью сама:
   - просканирует Inbox (+ `Lab/Models/Inbox`);
   - **авто** проставит размер, где имя ясное (`Goblin` → маленький, `Wolf` → четвероногие средние…);
   - откроет окно с **кнопками** размеров.
4. Для оставшихся: выбери слева → нажми размер справа. Готово.
5. Когда разметил пачку — `линейка существ` (или позже кнопка) → Blender рядом с Шаней.

В чат можно написать `разметить существ` — то же самое.

---

## Зачем это

Много моделей → несколько **классов роста**. Анимации пишутся на класс, не на каждого монстра.

---

## Почему «в папке 66», а скан говорит 103

Считается **каждый файл** (`.fbx` / `.blend` / `.glb`…), рекурсивно, плюс `Lab/Models/Inbox`.  
Одна папка с тремя экспортами = три записи. В окне разметки файлы с **одинаковым именем** размечаются вместе (нажал размер на `.fbx` — `.blend` тоже).

---

## Блендшейпы / morphs

Уши, хвосты, гениталии (в т.ч. «спрятанный» орган → morph вытянуть) — **не трогаем**.  
Разметка сейчас только класс роста. Lineup = импорт + scale корня.

## Старые текстовые команды (не нужны каждый день)

| Команда | Зачем |
|---------|-------|
| `сканируй существ` | только скан (+ авто по имени) |
| `авторазметка существ` | только авто |
| `очередь существ` | список текстом |
| `creature_catalog_set_size …` | вручную, если очень надо |
| `линейка существ` | подготовка Blender lineup |
