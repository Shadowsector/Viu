# Монстры: что делать по шагам

Обновление Вью тянет ветку **`cursor/viu-agent-core-65c2`**.  
После «Обновить Вью» перезапусти окно.

---

## Главное (без консольных команд)

1. Положи модели в `U:\Anabarra\Library\Lab\Creatures\Inbox\`
2. **«Разметить существ»** — скан + авто по именам + кнопки размеров.  
   При ошибке роста: галка «уже размеченных» + поле **Точный рост (м)**.
3. **«Линейка существ»** — Blender сама.  
   - `creature_lineup_overview.blend` — **по одному** из каждого класса (быстрый взгляд).  
   - `creature_lineup_small.blend` и т.п. — **все** этого класса.  
   - Авто **front/side PNG** → `Lab/Creatures/Processed/<slug>/` + поля `photo_*` в каталоге.
4. Смотри таблички: цель / факт. Оружие и пропы в замер роста не входят.

В чат: `разметить существ` / `линейка существ`.

---

## Что дальше после линейки (когда рост ок)

Порядок такой — **не прыгаем через шаги**:

1. **Добить разметку** — все нужные монстры с верным классом/ростом; спорные перепроверить в `creature_lineup_<класс>.blend`.
2. **Инвентаризация morphs** (уши / хвост / genital reveal) — список shape keys, ничего не bake’аем вслепую.
3. **Аккуратная нормализация** — текстуры/pack при необходимости, без убийства morphs.
4. **Genital / NSFW-риг** — где morph уже есть, используем его; иначе эталонный prefab + flaccid по умолчанию.
5. **A-pose фото** — после линейки PNG уже в Processed; иначе вручную → seed для Comfy, как у Шани.
6. **Сокеты на девушках** в Unity (oral / vaginal / anal / руки / cleavage) и стыковка с penetrator aim.

Пока шаги 2–6 **ещё не кнопки** — скажи, с какого начинать кодить (логично с morph-инвентаря или с сокетов Шани).

- Рост: ROOT-empty + AABB **тела** (armature-меши; sword/weapon/prop пропускаются).
