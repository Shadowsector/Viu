# Как отделить переднюю стенку сарая (Blender)

Когда стены **наслоены** и Separate по граням не работает — режем **секущей плоскостью**.

## Способ 1: Bisect (быстрее всего)

1. Открой `*_prepared.blend`.
2. Выдели **меш сарая** (коллекция Building) → **Tab** (Edit Mode).
3. **Alt+Z** — X-Ray, чтобы видеть обе стены.
4. **A** — выделить всё (или только зону у фасада, если боишься задеть крышу).
5. **Mesh → Bisect** (или **F3** → набери `Bisect`).
6. **ЛКМ + перетаскивание** — проведи линию реза. Плоскость должна отрезать **полоску передней стенки** снаружи.
   - Поверни вид (**NumPad 1 / 3**) — смотри сбоку, линия реза **вертикальная**, режет «лицевую» часть.
7. Внизу панель Bisect:
   - **Clear Inner** или **Clear Outer** — смотри, что остаётся; цель: **отделить передний слой**, не вырезать весь сарай.
   - **Fill** — обычно **выкл** (нам не нужна крышка на срезе).
8. **Enter** — применить.
9. Выдели грани **только отрезанной стенки** (или **L** под курсором на одной грани стенки).
10. **P → Separate → Selection** → новый объект.
11. Переименуй в **Wall_Front**. Оставь в коллекции Building.
12. **Tab** → Object Mode → **Ctrl+S**.

`Wall_Front` **не удаляем** — в Unity его скроют, когда Шаня внутри.

## Способ 2: Plane + Knife Project (если Bisect промахивается)

1. Object Mode → **Add → Mesh → Plane**.
2. Поставь plane **перед фасадом**, масштабируй (**S**), поверни (**R**) — как секущая плоскость.
3. Выдели **сначала Plane**, потом **сарай** (Shift-клик).
4. Сарай → Edit Mode → **Mesh → Knife → Knife Project**.
5. На плоскости реза: **Separate → Selection** → `Wall_Front`.
6. Удали или спрячь Plane-заготовку.

## Способ 3: Boolean (грубо, но работает)

1. Add → **Cube**, растяни в тонкую «ломтик»-стенку там, где должен быть `Wall_Front`.
2. Сарай: **Modifier → Boolean → Difference** (или Intersect для вырезания только пересечения).
3. Apply → отделённый кусок переименуй.

## Куда смотреть камерой

- **Dollhouse** = стенка **к экрану** (передняя), не та, где дверь сбоку.
- Дверь слеva — ок; режем всё равно **фасад к камере**.
