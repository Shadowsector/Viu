# Живая Вью: память событий, фантазия, инициатива

Не раздуваем `reflect_mode.py`. Личный голос остаётся коротким; жизнь держим в отдельных слоях.

## Три слоя (не путать)

| Слой | Файл | Что это |
|------|------|---------|
| Голос | `Anabarra/ViuPrompts/reflect_mode.py` | Кто она, тон, JSON |
| События | `.viu/event_memory.json` | Короткие биты сцен; переживают рестарт; можно гибридизировать |
| Лор | `.viu/LORE_DIGEST.md` | Биомы, существа — правит Ден |
| Мечта | `.viu/vision.md` | Отношения Вью↔Ден↔Шаня |
| Логи чата | `.viu/logs/chat_*.txt` | Сырьё; **не** память «личности» |

Сырые логи после рестарта в чат почти не возвращались — поэтому «забывала». Теперь в bare/heartbeat едет **digest событий**, не весь диалог.

## Как копятся события

1. Вью в JSON сцены может прислать `event_update` (title / what / where / senses / tags / hybrid_of).
2. Если не прислала, а сцена длинная — Вью сама вырежет бит (`maybe_capture_scene_event`).
3. В следующем чате и в heartbeat видит последние события + подсказку «смешай A+B».

## Несколько пузырей

На сцены — hint на `final_parts` из 2–3 сообщений (завязка / тело / ощущение). Списки «N событий» — как раньше.
