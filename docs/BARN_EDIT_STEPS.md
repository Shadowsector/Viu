# Сарай — клик за кликом (для Дена, без жаргона)

Ты **не** должен ничего «программировать». Только Unity: клики мышью и пара цифр.

**Окно Unity** (запомни три панели):

| Где на экране | Как называется | Зачем |
|---------------|----------------|--------|
| Слева | **Hierarchy** (иерархия) | Список всего в сцене — Шаня, дом, камера… |
| Посередине | **Scene** / **Game** | Картинка мира / то, что «игра» |
| Справа | **Inspector** (инспектор) | Настройки выбранного объекта |

Сверху меню: **File**, **Edit**, … и пункт **Viu**.

Сцена, которую открываем: **`OverlayDesktop`**  
(путь примерно `U:\Anabarra\Unity\Anabarra\Assets\…\OverlayDesktop.unity`).

---

## Шаг 0. Открыть сцену и сохранить «на всякий»

1. Запусти **Unity** с проектом Анабарра.
2. Внизу слева панель **Project** (файлы проекта). В поиске сверху набери: `OverlayDesktop`.
3. Дважды кликни файл **OverlayDesktop** (иконка сцены).
4. Нажми **Ctrl+S** (сохранить). Дальше перед большими правками тоже Ctrl+S.

**Не нажимай** в меню `Viu → Overlay → Bootstrap Overlay Scene (once)`, если дом/Шаня **уже** видны в Hierarchy. Bootstrap — «сборка с нуля»; он может сбить то, что уже стоит.

---

## Шаг 1. Есть ли «ящики-метки» Viu_Anchors?

«Пустышка» = пустой объект-метка в списке слева. Её **не рисует** игра; она говорит коду: «здесь дверь», «здесь старт Шани».

### Как найти

1. Кликни в панель **Hierarchy** (слева).
2. Вверху Hierarchy есть строка поиска — набери: `Viu_Anchors`.
3. Смотри результат:

**А) Нашлось `Viu_Anchors`**  
Раскрой стрелочкой слева. Внутри должны быть примерно такие имена:

- `Anchor_CharacterStart`
- `Anchor_BarnEntrance`
- `Anchor_HomeRoot`
- `Anchor_TaskbarFeetLine`

Если все четыре есть — **якоря уже стоят**. На шаге 1 больше ничего не делай. Переходи к **шагу 2 (камера)**.

**Б) Ничего не нашлось / не хватает якорей**  
Не создавай руками. Пусть Unity/Viu создаст:

1. Меню сверху: **Viu → Overlay → Validate Overlay Scene**.
2. Подожди пару секунд. В Console (внизу) может появиться строка вроде «Якоря Viu_Anchors/ созданы…».
3. Снова поиск `Viu_Anchors` в Hierarchy — должны появиться.
4. **Ctrl+S**.

Если после Validate якорей всё равно нет — напиши Вью/Cursor: «Validate не создал Viu_Anchors» (тогда разберём отдельно). **Не** жми Bootstrap «на удачу».

## Шаг 2. Камера внутри сарая (самое полезное сейчас)

**Зачем:** когда Шаня заходит внутрь, картинка слишком мелкая или обрезанная. Мы чуть «приближаем» только режим «внутри дома».

### 2.1. Найти камеру

1. Hierarchy → поиск: `Main Camera` (или просто `Camera`).
2. Кликни объект камеры **один раз** (он подсветится).
3. Справа в **Inspector** прокрути список компонентов вниз.
4. Найди блок с названием **`Overlay Camera Presets`** (или `OverlayCameraPresets`).

Если такого блока **нет**:

1. Меню **Viu → Overlay → Validate Overlay Scene**.
2. Снова кликни камеру. Если блока всё ещё нет — скажи Cursor’у; руками компонент лучше не клепать.

### 2.2. Поменять только «внутри» (Instance)

Внутри `Overlay Camera Presets` три секции: **Facade**, **Corridor**, **Instance**.

- **Facade** = снаружи у таскбара → **не трогай**, если снаружи уже нормально.
- **Corridor** = идёт к сараю → **не трогай**.
- **Instance** = **внутри** сарая → **вот это крутим**.

Раскрой **Instance**. Найди поле **Orthographic Size** (размер картинки):

| Число | Эффект |
|------|--------|
| больше (например 3–4) | всё мельче, «дальше» |
| меньше (например 2.0–2.2) | крупнее, «ближе», уютнее |

Поставь для начала **`2.15`**.  
Рядом **Feet Screen Fraction** — поставь **`0.10`**, если видишь такое поле.

**Ctrl+S**.

### 2.3. Проверить в игре

1. Сверху большая зелёная кнопка **▶ Play**.
2. Кликни окно **Game** (чтобы клавиатура шла в игру, не в редактор).
3. Клавиша **W** — Шаня идёт «вглубь» к сараю. У двери должна зайти **внутрь**.
4. Смотри: видны ли пол и задняя стена? Не режет ли потолок/ноги слишком сильно?
5. Мало уюта / слишком мелко → Stop (■), чуть уменьши Orthographic Size (например `2.0`), Ctrl+S, снова Play.
6. Слишком крупно / обрезано → увеличь Size (например `2.3`).
7. Клавиша **S** — должна вывести обратно наружу.
8. Stop → **Ctrl+S**.

На сегодня **этого достаточно**, если внутри уже «комната», а не космос.

## Шаг 3. Якоря двигать — только если вход/выход кривой

Делай **только если** при Play:

- W не ведёт к двери, или  
- у двери не заходит внутрь, или  
- S не возвращает на фасад.

Иначе **пропусти** этот шаг.

### Как подвинуть метку

1. Hierarchy → `Viu_Anchors` → кликни нужный якорь, например `Anchor_BarnEntrance`.
2. В середине включи вид **Scene** (вкладка рядом с Game).
3. Сверху инструменты: стрелки **Move** (иконка креста со стрелками) или клавиша **W** в редакторе (это не ходьба Шани — в Scene это «двигать объект»).
4. Потяни стрелки на объекте:

| Якорь | Куда глазами |
|--------|----------------|
| `Anchor_CharacterStart` | туда, где Шаня должна стоять **снаружи** у низа экрана |
| `Anchor_BarnEntrance` | **у двери** сарая (порог) |
| `Anchor_HomeRoot` | примерно **середина пола внутри** сарая |
| `Anchor_TaskbarFeetLine` | можно **не трогать** |

5. Play → проверь W/S → Stop → Ctrl+S.

Не нужно «ставить Kind» вручную — у готовых якорей Kind уже прописан.

## Шаг 4. Передняя стенка (кукольный дом)

**Зачем:** снаружи виден фасад; внутри передняя стенка должна **пропасть**, чтобы был виден интерьер.

1. Play → зайди внутрь (W).
2. Передняя «улица»-стенка **скрылась**, виден пол/мебель?  
   - **Да** → шаг 4 готов, ничего не делай.  
   - **Нет** → это уже правка модели/ссылки стены; напиши Cursor’у «внутри стенка не пропадает» — не ломай меш наугад.

---

## Шаг 5. Чтобы внутри было «живо» (мебель)

Пустой сарай = серый ящик. Нужны хоть 2–3 предмета **внутри**.

### Простой путь

1. Возьми готовые модели (FBX/prefab), которые уже есть в проекте, **или** кинь в `U:\Viu\Inbox` и дай Вью разобрать Inbox.
2. В Unity: из Project перетащи стул/коврик/свечу в **Scene** внутрь сарая (рядом с полом).
3. Play: зайди внутрь — предметы видны?
4. В окне **Вью** кнопка **«Разметить предметы»** — отметь: стул = sit, коврик = sleep и т.д.

Без анимаций sit/sleep Шаня всё равно будет в основном ходить — это отдельно (Mixamo), не блокер для «уютной камеры».

### Свет (по желанию)

1. Меню **GameObject → Light → Point Light**.
2. Перетащи лампочку внутрь сарая (над столом).
3. Справа в Inspector: **Color** — тёплый жёлтый; **Intensity** — маленькая (около 0.5).
4. Ctrl+S.  
**Не включай** странные HDR-галочки на камере оверлея — прозрачное окно может сломаться.

## Шаг 6. Чеклист «на сегодня хватит»

- [ ] Открыл OverlayDesktop, Ctrl+S  
- [ ] Нашёл или создал через Validate: `Viu_Anchors`  
- [ ] У камеры в **Instance → Orthographic Size** ≈ 2.0–2.3  
- [ ] Play: W внутрь — пол и стена видны; S наружу  
- [ ] (Опционально) стул + тёплый свет внутри  

---

## Чего **не** делать

- Не Bootstrap, если сцена уже с домом и Шаней.  
- Не править Facade/Corridor «на глаз», пока снаружи ок.  
- Не удалять Шаню / дом / Main Camera.  
- Не ждать, что Cursor сам подвинет камеру на твоём ПК — нужны **твои** клики в Unity; Cursor пишет «куда ткнуть».

Застрял на конкретном шаге (например «поискал Viu_Anchors — пусто») — напиши **номер шага + что видишь на экране**, разберём точечно.
