# Сарай — пошаговое редактирование (для Дена)

Сцена: `U:\Anabarra\Unity\Anabarra\Assets\…\OverlayDesktop.unity`  
**Не** пересоздавай сцену кнопкой Bootstrap, если дом уже стоит — только правь и Ctrl+S.

---

## 0. Открыть и не сломать

1. Unity → открой **OverlayDesktop**.
2. Hierarchy: найди дом/сарай (часто под Environment / Home).
3. Найди пустышку **`Viu_Anchors`** (или создай через меню Viu → Bootstrap только если якорей нет).
4. Сохрани сцену (Ctrl+S) перед большими правками.

---

## 1. Камера внутри сарая (Instance)

**Зачем:** сейчас внутри «не уютно» — кадр слишком общий или ноги/потолок режутся.

1. Hierarchy → Main Camera (overlay).
2. Компонент **`OverlayCameraPresets`**.
3. Блок **Instance**:
   - `Orthographic Size` ≈ **2.0 … 2.3** (меньше = крупнее / ближе).
   - `Feet Screen Fraction` ≈ **0.08 … 0.12**.
4. Play → клавиша **W** до двери → вход внутрь.
5. Крути Size, пока виден **пол + задняя стена + хотя бы один prop**.
6. Stop → Ctrl+S.

Facade/Corridor **не трогай**, пока Facade снаружи ок.

---

## 2. Якоря (если вход/выход кривой)

Под `Viu_Anchors/`:

| Объект | Куда поставить |
|--------|----------------|
| `Anchor_CharacterStart` | Где Шаня стоит у таскбара (снаружи) |
| `Anchor_BarnEntrance` | У **двери** сарая (дальний край коридора) |
| `Anchor_HomeRoot` | Центр пола **внутри** сарая |
| `Anchor_TaskbarFeetLine` | Линия стоп (ориентир, можно не двигать) |

На каждом — компонент `OverlaySceneAnchor` с нужным Kind.

Play: **W** должен вести к двери; у двери — вход; **S** — выход на фасад.

---

## 3. Кукольный дом (передняя стенка)

1. Найди объект с **`DollhouseWall`** (передний фасад, который должен пропадать внутри).
2. Play → зайди внутрь: передняя стенка **скрылась**, интерьер виден.
3. Если не скрылась — в DollhouseWall проверь ссылку на меш/рендереры передней стенки (см. `docs/BUILDING_WALL_CUT.md` для нарезки в Blender).

---

## 4. «Жизнь» внутри — props (минимум)

Внутри сарая должны стоять **реальные объекты**, не пустой ящик:

| Положи | В Viu разметь |
|--------|----------------|
| Стул / лавка | sit |
| Коврик / солома | sleep |
| Стол | lean |
| Чаша / яблоко | tableware / food |
| Свеча | decor |

Разметка: GUI **«Разметить предметы»** или prop catalog.

Без клипов sit/sleep Шаня всё равно только ходит — качай Mixamo по `SHANYA_ANIMATIONS.md`.

---

## 5. Свет (простой)

1. Create → Light → **Point Light** над столом / у окна.
2. Color: тёплый (оранжево-жёлтый), Intensity низкая (0.3–1 в URP).
3. **Не** включай HDR на overlay-камере (сломает прозрачность окна).

---

## 6. Проверка «готово»

- [ ] Снаружи: фасад читается, Шаня у низа экрана  
- [ ] W → мельче, к сараю; у двери → внутрь  
- [ ] Внутри: пол, задняя стена, стул/свет видны  
- [ ] S → снова фасад, камера не улетает  
- [ ] Ctrl+S; Viu → Validate overlay (по желанию)

---

## Если правишь меш сарая в Blender

1. Правишь `.blend` → экспорт через Viu (`export_unity_asset` / пайплайн сарая).  
2. Rebind материалов («Починить текстуры оверлея»).  
3. Сцену якорей **не** сбрасывать.  
Подробнее: `ASSET_PIPELINE.md`, `BUILDING_WALL_CUT.md`.
