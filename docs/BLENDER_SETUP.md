# Мост «Вью ↔ Blender» — как подключить (простыми словами)

Этот мост даёт Вью два умения:

1. **Читать бленд-файл в фоне** — узнать, что за модель, какие кости, блендшейпы,
   материалы (Blender при этом даже не нужно открывать).
2. **Управлять запущенным Blender вживую** — пока у тебя открыт Blender, Вью
   может смотреть сцену, двигать блендшейпы, вызывать команды (аналог нажатия
   кнопок) и делать снимок окна для «зрения».

---

## Часть А. Живое управление (Blender открыт)

### Шаг 1. Установить надстройку в Blender

1. Открой Blender.
2. Меню **Edit → Preferences → Add-ons**.
3. Нажми стрелочку в правом верхнем углу → **Install from Disk…**
   (в старых версиях просто кнопка **Install…**).
4. Выбери файл:
   `viu/integrations/blender/bridge_addon.py` (из этого проекта).
5. В списке появится **Viu Bridge** — поставь галочку, чтобы включить.

После включения в системной консоли Blender появится строка:
`[Viu Bridge] слушаю http://127.0.0.1:8765/`

> Если хочешь другой порт — задай переменную окружения `VIU_BLENDER_PORT`
> **до** запуска Blender (и такую же для Вью).

### Шаг 2. Проверить связь со стороны Вью

Пока Blender открыт, попроси Вью узнать про сцену:

```bash
python -m viu run "Расскажи, что за модель сейчас открыта в Blender"
```

Вью вызовет инструмент `blender_info` и вернёт список объектов, костей,
блендшейпов и материалов.

---

## Часть Б. Чтение файла в фоне (Blender закрыт)

Чтобы Вью могла читать `.blend` без открытого Blender, укажи ей путь к
программе Blender (файл `blender.exe`):

```bash
set VIU_BLENDER_EXE=C:\Program Files\Blender Foundation\Blender 5.1\blender.exe
python -m viu run "Изучи файл u:\Anabarra\Blender_Files\shanya.blend"
```

(Portable-версия — просто путь к её `blender.exe`.)

---

## Что Вью уже умеет через мост

| Инструмент | Что делает |
|---|---|
| `blender_info` | сведения о сцене/файле (объекты, кости, блендшейпы, материалы) |
| `blender_command` | выполнить команду в живом Blender |
| `blender_screenshot` | снимок окна Blender (для vision-модели) |

Команды `blender_command`:

- `ping` — проверка связи;
- `scene_info` — вся сцена;
- `object_info` (name) — подробности по объекту;
- `list_shape_keys` (object) — список блендшейпов и их значения;
- `set_shape_key` (object, key, value) — задать значение блендшейпа;
- `run_operator` (operator, args) — вызвать любую команду Blender
  (например, `mesh.primitive_cube_add`) — это и есть «нажатие кнопки»;
- `screenshot` (path) — снять окно.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `VIU_BLENDER_EXE` | `blender` | путь к `blender.exe` (для чтения в фоне) |
| `VIU_BLENDER_HOST` | `127.0.0.1` | адрес моста |
| `VIU_BLENDER_PORT` | `8765` | порт моста |

## Осторожно

`run_operator` может выполнить почти любую команду Blender. Мост слушает только
локально (`127.0.0.1`), но всё же не оставляй его открытым для непроверенных
программ. По умолчанию Вью работает по принципу «предложила → ты одобрил».
