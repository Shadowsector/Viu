# Студия существ — пошагово для Дена

**Главная кнопка:** **Студия существ** (не «Линейка» — та для массового headless).

---

## Зачем

Раньше «Линейка» гоняла **все 96 моделей** в фоне: долго, IK в кадре, Facehug мерился не тем мешем, все стоят далеко и кто как повёрнут.

**Студия** = Blender с панелью **Viu** (клавиша `N` → вкладка Viu): Шаня слева, **одно** существо справа. Ты чистишь, правишь рост, снимаешь скрины, сохраняешь эталон.

---

## Шаг 1 — файл в Inbox

```
U:\Anabarra\Library\Lab\Creatures\Inbox\wolf_alpha.blend
```

**Единый Inbox** для всех живых существ. `Models\Inbox` — только Шаня/humanoid, не волки.

Имя файла → slug `wolf_alpha`.

### Только WGT в Blender, тела не видно?

Rig-виджеты (`WGT.Foot.L` …) — не тело. На панели Viu: **Показать меши тела** / **Спрятать IK**.

Если тела всё равно нет — в `.blend` нет mesh (только риг). Экспортируй FBX с телом или открой полный blend в `Creatures\Inbox`.

## Шаг 2 — Разметить размер (один раз)

**Разметить существ** → галочка **«Показать уже размеченных»**.

Почему волка не было в списке без галочки: если в имени `wolf`, Вью **уже авторазметила** `quad_med` — это не «новый», а «размеченный».

Выбери волка → класс **quad_med** → рост **0.96** (если знаешь холку) → кнопка размера.

---

## Шаг 3 — Blender-студия

1. **Студия существ** (или в разметке: **Открыть Blender-студию** на волке)
2. В Blender: **N** → вкладка **Viu**
3. На панели:
   - **Спрятать IK** — убрать empties / rig-helpers (не удаляй скелет!)
   - Вручную удали/спрячь лишние mesh (мечи, дубли)
   - **Рост (м)** → **Применить рост**
   - **Снять скрины** → `Processed\wolf_alpha\front.png` + `side.png`
   - **Сохранить эталон** → `wolf_alpha_ready.blend` в той же папке
   - **Скрины ок ✓** (если устраивает) или **Скрины плохие** + заметка
4. **Следующее** / **Предыдущее** — другие существа в очереди
5. Закрой Blender

## Шаг 4 — забрать результат во Вью

**Синхр. студии** — подтянет скрины, рост, `photo_ok`, путь к эталону в каталог.

Проверка в чате: `creature_catalog_show mode=all`

## IK и текстуры

| Проблема | Что делать в Blender |
|----------|-------------------|
| IK, pole, ctrl в кадре | **Спрятать IK** + коллекция Helpers → hide render |
| Не тот меш для роста (Facehug) | Выбери правильный mesh глазами, поправь рост вручную |
| Серый силуэт | Текстуры внутри `.blend` или папка `textures/` рядом с Inbox |
| Два файла fbx+blend | Студия берёт `.blend` в приоритете (как линейка) |

**Не удаляй armature** — только hide helpers.

## Когда «Линейка существ»

Только если нужно **массово** переснять пачку без ручной чистки:

```text

```

Для обычной работы — **Студия**.
