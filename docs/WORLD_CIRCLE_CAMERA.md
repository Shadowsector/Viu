# Круговой мир и камера 2.5D (сарай и поход)

> Зафиксировано с Деном, июль 2026. Дополняет `VISION.md` §6.5 и `OVERLAY_MODES.md`.

## Идея в двух словах

Мир вокруг дома — **не полоса Terraria** и не плоский боковик. Это **круг** (диск): дом в центре, Шаня бегает в **любом** направлении по плоскости XZ. Камера всегда показывает её **сбоку** (~30–40° сверху), как в Palia / Animal Crossing внутри дома — мягкая **2.5D-изометрия**, не ортографический «плакат».

Интерьеры (сарай, лавка, баня) — **фасад + cutaway** (кукольный домик): стены частично скрываются, видно, где Шаня и что делает.

## 1. Круговой мир

```
        вид сверху (схема)

              N (+Z)
               |
    W (-X) — [ДОМ] — E (+X)
               |
              S (-Z)

Шаня бегает по кругу/диску вокруг якоря «дом».
На экране — всегда профиль (камера сбоку).
```

| Ситуация | Поведение |
|----------|-----------|
| Дома | Мир **не сдвигается**; cutaway-стены; камера чуть ближе и круче (Instance) |
| Вышла из дома | Начинается **поход**; мир (корень `Viu_WorldRoot`) **уплывает** противоположно движению — Шаня остаётся в центре кадра |
| Идёт «домой» | Камера **переворачивается на другой бок** (yaw +180°), чтобы возвращение читалось иначе, чем уход |
| Нашла новый дом за 2 км | **Сдвиг якоря**: новый дом = новый центр круга; старый уезжает на периферию графа (не дублируем две Шани) |

Топология дальше по карте — **снежинка** из `VISION.md` (лучи под косыми углами, перемычки). Круг — **локальная** метрика вокруг текущего якоря-дома, не вся карта целиком.

## 2. Камера

### Углы

| Режим | Pitch (↓) | Ortho | Назначение |
|-------|-----------|-------|------------|
| **Facade** | ~28° | ~5.5 | Дом у таскбара, фасад |
| **Corridor** | ~32° | ~5.5 | Подход к двери |
| **Instance** | ~38° | ~2.15 | Интерьер, cutaway |
| **Activity** | ~42° | ~1.85 | Готовит, спит, играет — чуть ближе |

Камера смотрит с **−Z** (к экрану), yaw задаёт «с какого бока» профиль.

### Плавные переходы

- **Вход в комнату** — за ~0.45 с: ortho ↓, pitch ↑, dollhouse-стена скрывается (`OverlayCameraBlend`).
- **Выход** — обратно к Facade.
- **Поход / разворот домой** — `WorldOrbitController` меняет yaw (другой бок).

### Cutaway

Уже есть: `DollhouseWall` + `open_wall` в Blender (`BUILDING_WALL_CUT.md`). Для 2.5D интерьера ассеты с **объёмом** (пол, мебель по глубине), не спрайтовая стена.

## 4. Фазы внедрения

### A — Интерьер сарая (сейчас)
- Pitch ~38° в Instance, плавный вход/выход
- Дотюнить cutaway и props (`BARN_EDIT_STEPS.md`)
- **Проверка:** зайти в сарай — камера мягко приближается, стены не мешают, видно Шаню у кровати/стола

### B — Поход по кругу
- `WorldOrbitController.expeditionEnabled = true`
- A/D/W/S → движение по XZ относительно камеры
- Мир сдвигается, дом уплывает; yaw при «домой»

### C — Новый дом = новый центр
- `SetHomeAnchor(newHome, distance)` + сохранение в save/Viu memory
- Камера и граф снежинки согласуют ветку

### D — Activity zoom
- При affordance (спит, готовит) → пресет **Activity** на время действия

## 6. Арт-направление (2.5D)

- **Снаружи:** фасад с глубиной (выступы, крыша, тень).
- **Внутри:** пол виден, мебель смещена по Z; персонаж **между** предметами, не наклеен на фон.
- Референсы: Palia interiors, Animal Crossing rooms — не Terraria-тайл.

Отход от Terraria = **не отказываемся от ortho** (нужен для оверлея и таскбара), но добавляем **pitch + объёмные ассеты + cutaway**.
