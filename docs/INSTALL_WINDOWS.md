# Установка и обновление Viu на Windows

## Коротко

В корне `U:\Viu` теперь **один файл запуска — `Viu.cmd`**. Двойной клик по нему:
проверяет обновления, ставит пакет, открывает окно. Если что-то сломается —
окно останется с текстом ошибки.

## Как обновляться

Есть три равнозначных способа, выбирай любой:

1. **Автоматически при запуске** — `Viu.cmd` каждый раз тянет свежую версию сам.
2. **Кнопкой в окне** — «Обновить Вью» (проверить → скачать → установить в один шаг).
3. **Ничего не делать** — если обновлений нет, всё просто запускается.

## Почему обновление иногда не срабатывает

Репозиторий **Shadowsector/Viu** сейчас **приватный**. Для скачивания GitHub
требует авторизацию, поэтому автообновление у постороннего компьютера молча
пропускается (Вью при этом всё равно открывается).

Чтобы автоматика заработала полностью, выбери один из вариантов:

### Вариант А — сделать репозиторий публичным (проще всего)

GitHub → репозиторий Viu → **Settings** → внизу **Change repository visibility**
→ **Public**. После этого `Viu.cmd` и кнопка «Обновить Вью» работают без токенов.

### Вариант Б — оставить приватным и вписать токен

1. GitHub → **Settings** → **Developer settings** → **Personal access tokens**
   → создать токен с доступом на чтение репозитория.
2. В `Viu.cmd` раскомментировать строку и вставить токен:
   ```bat
   set VIU_GITHUB_TOKEN=ghp_твой_токен
   ```
3. С этим же токеном заработает и кнопка «Отправить логи разработчику»
   (Вью зальёт логи в приватный Gist и даст ссылку).

## Если окно не открывается

Запусти **`diagnose.bat`** — окно не закроется и покажет проверку Python,
tkinter, установки пакета и запуска. Пришли этот текст разработчику.

## Отправить логи разработчику

В окне Вью, группа **«Вью»** → кнопка **«Отправить логи разработчику»**.
Вью соберёт логи в один `.zip` в `\.viu\support\`. Если задан токен —
сразу зальёт на GitHub и покажет ссылку; иначе просто откроет папку с файлом,
который можно перетащить в чат Cursor.

## Папки

| Папка | Что внутри |
|-------|------------|
| `Viu.cmd`, `diagnose.bat`, `run_gui.pyw` | запуск и диагностика |
| `legacy_scripts/` | старые bat-файлы (не нужны, лежат на всякий случай) |
| `setup/` | `make_shortcut.bat` — ярлык на рабочий стол |
| `.viu/` | логи, память, собранные логи (`support/`) |
